# AZS Speed Controller v1.3.2

The run timer again accelerates beyond ×5 on the maintainer’s Azeroth Survivors
**0.139.0** Windows client. Instead of pinning one 0.127.0 EXE hash, the hook
scans the loaded image for the local simulation wait and scales only that call.

## What's new

- Signature-based chrono fix (no fixed PE timestamp / file SHA gate).
- Status: **Chrono: armed**, **Chrono: call observed**, or **Chrono fix unavailable**.
- Same overlay, shortcuts, custom speeds and profiles as 1.3.x.
- Classic clock hooks kept when chrono cannot arm.

## Update

Close the game and any previous controller completely. Extract
`AZS-Speed-Controller-v1.3.2-Windows-x64.zip`, keep EXE and DLL together, launch
the game then the controller. F6 returns to ×1. No game files are modified.

## Limits

Windows x64 only. Unofficial. DLL injection may trigger antivirus heuristics.
Not affiliated with the game developers. Offline / single-player use intended.
Future game builds that change the wait prologue need a new pattern match.
